# Ahnaf Fathan Nabiha: portfolio

A single-page portfolio in plain HTML, CSS and JavaScript. No build step, no external requests.

## Files

- `index.html`: all text content. Edit this to change what the site says.
- `css/style.css`: styling. The four theme colors are at the top under `:root`.
- `js/app.js`: menu navigation, keyboard control, page transition, optional sound.
- `assets/`: photo, CV, completion letter, fonts.

## Preview locally

    python3 -m http.server

Then open http://localhost:8000

## Publish on GitHub Pages

1. Upload every file and folder here to the root of the repository `ahnaffathan04.github.io`.
2. In the repository, open Settings, then Pages, and set the source to the `main` branch, root folder.
3. The site appears at https://ahnaffathan04.github.io/ within a minute or two.

## Replace later

- `assets/photo.jpg`: use a square photo of at least 600 x 600 px, same file name.
- `assets/CV_Ahnaf_Fathan_Nabiha.pdf`: overwrite with the final CV, same file name.

## Controls

Arrow keys choose, Enter opens, Esc goes back. Mouse and touch work as well.
